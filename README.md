# Job Intel Portfolio

这个作品集包含岗位情报分析、深度学习、岗位情报站后端三个实践项目。岗位情报站采集了30条广深 AI 交叉岗位 JD，使用 DeepSeek 批量解析，并通过 pandas 完成统计和图表报告；NEU 钢面缺陷分类项目使用 PyTorch 从零训练 CNN，对六类缺陷进行分类。将输入分辨率从64提高到128、训练轮数从10增加到15后，准确率从60%多提升至约82%。

**Jir-Site 岗位情报站后端（FastAPI + RAG）**：开发了一套全链路的岗位情报 API 服务。底层用 Pandas 和 SQLite 搭建全量数据导入管道；中间层利用 BGE 模型（SentenceTransformer）将岗位 JD 向量化并存入本地 NPZ 库，实现毫秒级的语义检索（打破了传统关键词死板匹配的局限）；上层接入 DeepSeek API 实现 RAG 问答。核心亮点：设计了严格的 Prompt 防幻觉机制（带编号溯源、拒答无资料问题），并实现了 A/B 控制变量测试与边界防崩溃的全套 Pytest 单元测试。

我主要参与岗位数据采集、脚本理解与调试，以及图表和报告核对；岗位项目的主体代码由 AI agent 编写。NEU 项目基于 agent 模板完成训练，我亲自调整参数并记录结果，网络结构并非原创设计。Jir-Site 项目约70%代码由 AI 生成，AI 负责基础 CRUD 路由、Pydantic 校验模型的拼装、SQL/向量检索的底层实现；我负责整体架构设计、业务逻辑串联、Prompt 的防幻觉调优、Windows 环境（国内镜像/文件占用）的踩坑与修复，以及控制变量测试方案的设计。目前岗位分析只有30条样本，适合展示流程和观察趋势；NEU 项目尚未使用预训练模型或数据增强，仍存在过拟合风险，结果还有改进空间。
