# Job Intel Portfolio

这个作品集包含岗位情报分析与深度学习两个实践项目。岗位情报站采集了30条广深 AI 交叉岗位 JD，使用 DeepSeek 批量解析，并通过 pandas 完成统计和图表报告；NEU 钢面缺陷分类项目使用 PyTorch 从零训练 CNN，对六类缺陷进行分类。将输入分辨率从64提高到128、训练轮数从10增加到15后，准确率从60%多提升至约82%。

我主要参与岗位数据采集、脚本理解与调试，以及图表和报告核对；岗位项目的主体代码由 AI agent 编写。NEU 项目基于 agent 模板完成训练，我亲自调整参数并记录结果，网络结构并非原创设计。目前岗位分析只有30条样本，适合展示流程和观察趋势；NEU 项目尚未使用预训练模型或数据增强，仍存在过拟合风险，结果还有改进空间。
