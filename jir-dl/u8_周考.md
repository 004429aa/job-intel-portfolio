# U8 说人话周考：给外行讲"训练在干嘛"（20分钟，全程口头，零代码）
# 本单元没有代码。交付物 = 一段3-5分钟的口头讲解 + 一份考点自查清单
#
# 考题：假设你妈/你室友（完全不懂编程的人）问你："你这几天天天在电脑上跑的那个东西是啥？"
# 你要讲清楚以下六件事，全程不许说一个英文术语——说了就当没讲清。
#
# ---------- 六个考点 ----------
# 1. 数据：电脑里的图片是什么？（U2：28×28个0~1的小数，灰度深浅）
# 2. 模型：那个"网络"是什么？（U3：一个数学公式，里面有几万个可调的小数旋钮）
# 3. 开局：一开始它会认字吗？（U3：不会，旋钮随机乱填，猜对概率约1/10）
# 4. 训练：那怎么学会的？（U4+U5：猜→对答案算误差→算每个旋钮往哪边拧→拧一点，重复几万次）
# 5. 考试：怎么知道它真会了？（U5：留一万张它没见过的图考它，答对率从10%到98%）
# 6. 升级：换了个带滤镜的结构为什么更强？（U7：像人一样先看局部形状不是逐个像素）
#
# ---------- 规则 ----------
# - 找个没人的房间，掐表3-5分钟，开口讲，不许看任何笔记
# - 讲的时候手机录音，讲完自己听一遍
# - 听录音时对照上面六点打勾：哪点漏了？哪点自己都听不懂？哪点用了英文术语？
# - 每个没讲清的点，回去翻对应单元的注释重看，然后重讲那一段
#
# ---------- 为什么这个单元最重要 ----------
# 你第一周期的弱项就是"交付代码跳过口头阐述"。但面试官不懂你的代码，
# 只懂你嘴里的故事。代码是给机器的，故事是给人的——两样都得有。
# 这次讲稿直接成为你深度学习项目的面试pitch素材库。
