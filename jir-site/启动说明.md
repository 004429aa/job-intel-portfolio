# 岗位情报站 · 启动说明

## 环境

- Python: 3.14.6（路径 `D:\python\pythonpreservation\python.exe`）
- 依赖：fastapi / uvicorn / pandas / openpyxl / pydantic / pytest
- 安装命令：`"D:\python\pythonpreservation\python.exe" -m pip install fastapi uvicorn pandas openpyxl pydantic pytest`

## 数据库初始化

```
"D:\python\pythonpreservation\python.exe" jir_site_db.py
```

预期输出：

```
✅ 数据表初始化完成
✅ 一共插入 30 条岗位数据
```

## 启动API

```
"D:\python\pythonpreservation\python.exe" -m uvicorn jir_site_api:app --reload --port 8000
```

预期输出：

```
INFO:     Uvicorn running on http://127.0.0.1:8000
INFO:     Application startup complete
```

启动后浏览器访问 `http://127.0.0.1:8000/docs` 可打开交互式接口文档。

## 端点清单

| 方法 | 路径 | 参数 | 返回 |
|---|---|---|---|
| GET | /jobs | city / min_salary / keyword / limit | 岗位列表 |
| GET | /jobs/{id} | 路径参数 id | 单条岗位详情 |
| POST | /jobs | JSON 请求体 | 创建新岗位，返回 201 与新 id |
| DELETE | /jobs/{id} | 路径参数 id | 删除岗位，返回删除条数 |

## 故障排查

### 1）端口 8000 被占用（OSError: Address already in use）

方案 A：杀掉占用进程（Windows CMD）

```
netstat -ano | findstr :8000
taskkill /PID 12345 /F   （把数字替换成查到的PID）
```

方案 B：更换端口启动服务

```
uvicorn jir_site_api:app --reload --port 8001
```

### 2）中文乱码（数据库 / 控制台中文变成问号）

1. 代码文件编码：全部保存为 UTF-8
2. Git 全局配置（CMD 执行）：`git config --global core.quotepath false`
3. 启动前设置控制台编码：`chcp 65001`

### 3）ModuleNotFoundError：找不到模块

原因：Python 搜索路径找不到当前项目文件。

1. 临时解决（写在代码顶部）：`sys.path.insert(0, ".")`
2. 稳妥方案：在项目根目录（Jir-Site\）执行代码，不要在子文件夹运行脚本
3. 确认使用的是 `D:\python\pythonpreservation\python.exe`，不要混用多个 Python 版本

### 4）参数校验报错 422

检查：请求参数是否符合 Pydantic BaseModel 字段规则（字符串长度、薪资数值范围、非空校验）。
